# Guide: Converting `workspace.db` (SQLite) to JSON Format

This guide outlines step-by-step methods to export the SQLite database ([`long_nguyen/data/database/workspace.db`](file:///d:/computational_thinking/Computational-Thinking-Project/long_nguyen/data/database/workspace.db)) into `.json` or `.jsonl` format.

---

## 1. Overview of the Existing Database

The current `workspace.db` contains 4 relational tables:
* **`documents`**: Master document records (`document_id`, `title`, `source_url`, etc.).
* **`document_versions`**: Versioning, SHA-256 hashes, file sizes, and processing status.
* **`chunks`**: Text chunks extracted for RAG retrieval (`chunk_id`, `content`, `heading_path`, `line_start`, `line_end`, `token_count`).
* **`remediation_snippets`**: Structured code blocks (`snippet_id`, `programming_language`, `defense_tier`, `code_role`, `code_content`, line ranges).

Depending on your downstream use case, you can choose from the following export methods.

---

## 2. Method 1: Export Entire Database into a Single `workspace.json` (Recommended)

This method iterates over all tables in `workspace.db` and dumps them into a single nested JSON object.

### Python Script: `export_all_to_json.py`

Save or run the following Python script:

```python
import json
import sqlite3

# Paths relative to project root
DB_PATH = "long_nguyen/data/database/workspace.db"
OUTPUT_JSON = "long_nguyen/data/database/workspace.json"

def export_db_to_json(db_path: str, output_path: str):
    conn = sqlite3.connect(db_path)
    conn.row_factory = sqlite3.Row  # Access columns by name
    cursor = conn.cursor()

    # Discover user tables (ignoring internal sqlite metadata tables)
    cursor.execute("SELECT name FROM sqlite_master WHERE type='table' AND name NOT LIKE 'sqlite_%'")
    tables = [row[0] for row in cursor.fetchall()]

    database_data = {}

    for table in tables:
        cursor.execute(f"SELECT * FROM {table}")
        rows = [dict(row) for row in cursor.fetchall()]
        database_data[table] = rows
        print(f"[+] Exported table '{table}': {len(rows)} rows")

    with open(output_path, "w", encoding="utf-8") as f:
        json.dump(database_data, f, indent=2, ensure_ascii=False)

    print(f"\n[SUCCESS] Successfully saved full database dump to: {output_path}")
    conn.close()

if __name__ == "__main__":
    export_db_to_json(DB_PATH, OUTPUT_JSON)
```

## 3. Method 2: Export Tables into Individual JSON Files

If you want dedicated JSON dataset files for each table (e.g. `chunks.json` for RAG evaluation, `remediation_snippets.json` for red-team code benchmarks):

### Python Script: `export_tables_split.py`

```python
import json
import os
import sqlite3

DB_PATH = "long_nguyen/data/database/workspace.db"
OUTPUT_DIR = "long_nguyen/data/export_json"

def export_individual_tables(db_path: str, output_dir: str):
    os.makedirs(output_dir, exist_ok=True)
    conn = sqlite3.connect(db_path)
    conn.row_factory = sqlite3.Row
    cursor = conn.cursor()

    cursor.execute("SELECT name FROM sqlite_master WHERE type='table' AND name NOT LIKE 'sqlite_%'")
    tables = [row[0] for row in cursor.fetchall()]

    for table in tables:
        cursor.execute(f"SELECT * FROM {table}")
        rows = [dict(row) for row in cursor.fetchall()]
        out_file = os.path.join(output_dir, f"{table}.json")
        with open(out_file, "w", encoding="utf-8") as f:
            json.dump(rows, f, indent=2, ensure_ascii=False)
        print(f"[+] Saved {len(rows)} records -> {out_file}")

    conn.close()

if __name__ == "__main__":
    export_individual_tables(DB_PATH, OUTPUT_DIR)
```

## 4. Method 3: Export to JSON Lines (`.jsonl`) for RAG & Large Datasets

For large datasets (10,000+ chunks or records), **JSON Lines (`.jsonl`)** is industry best practice because:
1. Each line is an independent, valid JSON object.
2. It allows streaming and line-by-line reading without loading gigabytes into RAM.
3. It directly integrates with vector search engines, Hugging Face Datasets, and OpenAI/Anthropic/Gemini fine-tuning pipelines.

### Python Script: `export_to_jsonl.py`

```python
import json
import sqlite3

DB_PATH = "long_nguyen/data/database/workspace.db"
OUTPUT_JSONL = "long_nguyen/data/database/chunks.jsonl"

def export_table_to_jsonl(db_path: str, table_name: str, output_path: str):
    conn = sqlite3.connect(db_path)
    conn.row_factory = sqlite3.Row
    cursor = conn.cursor()

    cursor.execute(f"SELECT * FROM {table_name}")
    count = 0
    with open(output_path, "w", encoding="utf-8") as f:
        for row in cursor:
            f.write(json.dumps(dict(row), ensure_ascii=False) + "\n")
            count += 1

    print(f"[+] Exported {count} lines to {output_path}")
    conn.close()

if __name__ == "__main__":
    export_table_to_jsonl(DB_PATH, "chunks", OUTPUT_JSONL)
```

## 5. Method 4: Direct Export via SQLite CLI (Terminal One-Liner)

If you have the `sqlite3` CLI installed on your machine, you can export directly from PowerShell or bash without writing Python code:

### PowerShell
```powershell
# Export 'chunks' table to chunks.json
sqlite3 long_nguyen/data/database/workspace.db ".mode json" "SELECT * FROM chunks;" > long_nguyen/data/database/chunks.json

# Export 'remediation_snippets' table
sqlite3 long_nguyen/data/database/workspace.db ".mode json" "SELECT * FROM remediation_snippets;" > long_nguyen/data/database/remediation_snippets.json
```

## 6. Method 5: Using Pandas (Data Science Workflow)

If you work with `pandas` in Jupyter notebooks or Python:

```python
import sqlite3
import pandas as pd

conn = sqlite3.connect("long_nguyen/data/database/workspace.db")

# Export chunks table
df_chunks = pd.read_sql_query("SELECT * FROM chunks", conn)
df_chunks.to_json("long_nguyen/data/database/chunks.json", orient="records", indent=2, force_ascii=False)

# Export remediation snippets table
df_snippets = pd.read_sql_query("SELECT * FROM remediation_snippets", conn)
df_snippets.to_json("long_nguyen/data/database/remediation_snippets.json", orient="records", indent=2, force_ascii=False)

conn.close()
```
